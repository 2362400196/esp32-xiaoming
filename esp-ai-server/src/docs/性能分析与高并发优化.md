## 三、性能优化建议

### 3.1 高优先级优化

#### 优化 1: 连接池 - 减少锁粒度

**当前问题**：[ConnectionPoolBase](file:///c:/Users/23624/Desktop/hahahahaahaahha/esp-ai-server/src/infrastructure/connection_pool.py#L35) 使用单锁保护整个池

**优化方案**：
```python
# 改进的连接池设计（伪代码）
class OptimizedConnectionPool(ConnectionPoolBase):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self._acquire_sem = asyncio.Semaphore(3)  # 允许并行获取
```

#### 优化 2: 引入异步任务限流（Semaphore）

**添加位置**：[web.py](file:///c:/Users/23624/Desktop/hahahahaahaahha/esp-ai-server/src/infrastructure/web.py) 或 [session.py](file:///c:/Users/23624/Desktop/hahahahaahaahha/esp-ai-server/src/use_cases/session.py)

```python
# 新增：全局并发控制
_global_semaphore: asyncio.Semaphore | None = None

def init_global_semaphore(max_concurrent: int = 30):
    global _global_semaphore
    _global_semaphore = asyncio.Semaphore(max_concurrent)
    logger.info(f"[Concurrency] 全局并发限制: {max_concurrent}")
```

#### 优化 3: CPU 密集型任务移到线程池

**问题**：[EmotionRenderer.render_emotion_rgb565_b64](file:///c:/Users/23624/Desktop/hahahahaahaahha/esp-ai-server/src/use_cases/auxiliary_services.py#L264) 中的图片处理阻塞事件循环

**优化方案**：
```python
# 改进辅助服务，使用线程池处理图片渲染
import concurrent.futures

_process_pool: concurrent.futures.ThreadPoolExecutor | None = None

def init_process_pool(max_workers: int = 4):
    global _process_pool
    _process_pool = concurrent.futures.ThreadPoolExecutor(max_workers=max_workers)
```

### 3.2 中优先级优化

#### 优化 4: 消息缓存（LRU）

为对话历史添加 LRU 缓存，防止内存无限增长：
```python
from functools import lru_cache

# 在 domain/entities.py 中限制
@dataclass
class Conversation:
    messages: List[Message]
    _max_messages: int = 50  # 默认限制50条
    
    def add_message(self, message: Message):
        self.messages.append(message)
        if len(self.messages) > self._max_messages:
            self.messages = self.messages[-self._max_messages:]
```
