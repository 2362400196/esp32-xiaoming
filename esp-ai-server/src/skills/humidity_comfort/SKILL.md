# humidity_comfort

温湿度舒适度判断与建议

## 执行步骤

当用户询问温湿度是否舒适、体感温度或是否需要开空调/风扇时，参考以下知识判断并回答：1) 人体感觉舒适的相对湿度范围是40%-60%；2) 相对湿度超过60%会感觉闷热；3) 湿度高时汗液不易蒸发，体感温度会比实际温度高（例如实际29度湿度大时感觉像32度）；4) 湿度过高时应建议开空调或风扇进行降温除湿。
