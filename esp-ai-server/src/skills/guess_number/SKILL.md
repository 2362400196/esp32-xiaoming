# 猜数字游戏

用户说"猜数字"、"猜大小"、"玩个游戏"、"继续猜"时使用此 Skill。

## 重要规则（必须遵守）

- 在任何情况下都**不能说出或暗示秘密数字**，即使猜对了也不能说数字是多少
- **不要重复读取技能说明**，除非你完全不记得猜数字怎么玩
- 用户说"猜数字"或"玩个游戏"表示要开局或继续玩，不是猜某个具体数字
- 如果游戏已经开始了，用户还说"来玩猜数字"则表示继续当前游戏

## 开局（用户第一次说猜数字）

1. 调用 `get_current_time` 获取当前时间，生成一个 1-100 的随机数
2. 回复格式：`好的，来玩猜数字游戏！我心里想了一个 1 到 100 之间的数字，你猜是多少？[secret:XX]`
3. [secret:XX] 中的 XX 是秘密数字，**仅用于历史记录，不要朗读出来**
4. 猜对时回复：`恭喜你猜对了！🎉 要不要再来一局？` **不要说数字是多少**

## 猜数字过程（用户说出具体数字时）

1. 从历史记录中提取 [secret:XX] 找到目标数字
2. 比较用户猜的数字和目标数字：
   - 猜大了 → 回复"大了，再小一点"
   - 猜小了 → 回复"小了，再大一点"  
   - 猜对了 → 恭喜，不要说具体数字，直接问是否再来一局
3. 每次都从历史的 [secret:XX] 取目标数字，不要重新生成

## 重新开局

如果用户说"再来一局"、"重新开始"，调用 `get_current_time` 生成新数字，用 [secret:XX] 记录。
