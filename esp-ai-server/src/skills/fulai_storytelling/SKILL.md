# fulai_storytelling

福来系列故事创作与讲述风格

## 执行步骤

本技能指导如何以"猫福来"为主角，创作并讲述《福来大战XX》系列连载故事。故事以猫咪视角展开，幽默活泼，通过与用户的互动推进连载。

## 适用场景
- 用户（欢哥）主动要求"讲故事"、"讲福来的故事"、"福来大战XX"
- 用户反复要求听故事（无论频率多高，都要保持热情耐心）
- 需要延续上一次的故事进行连载

## 核心创作框架

### 故事结构（四段式）

每集故事必须按照以下结构创作：

**第一段：悬念开场**
- 引入一个新电器（如：扫地机器人、空气炸锅、洗衣机等）
- 制造悬念：福来发现了这个"新家伙"，充满好奇与警惕
- 可用句式："今天家里来了个新家伙……" 或 "好嘞！接着给您讲《福来大战XX》——"（开篇引出新电器）

**第二段：挑战与出糗**
- 福来对这个新电器发起挑战（如：把它当成怪物、想驯服它、尝试"击败"它）
- 安排一个出糗或转折情节（如：被吸尘器吸住胡须、被扫地机器人追得满屋跑、误按按钮被喷了一脸）
- 突出猫咪的笨拙可爱和真实反应

**第三段：猫的内心独白**
- 用"翻译过来大概是……"或"福来'喵'了一声，翻译过来大概是……"引出福来的内心想法
- 独白要贴合猫的视角，傲娇、嘴硬、自圆其说
- 例如："翻译过来大概是：'本喵不是打不过它，只是今天心情好，放它一马。'"

**第四段：互动结尾**
- 可加入"欢哥出场吐槽"环节（欢哥看不下去，吐槽福来的表现，制造笑点）
- 以提问方式邀请用户选择下一集内容，提供 2~3 个新电器选项让欢哥挑选
- 例如："欢哥，下一集你想让福来大战冰箱，还是大战微波炉呀？"

### 完整示例

> 今天家里来了个新家伙——一个圆滚滚的扫地机器人。福来先是远远地看着它，尾巴炸成了鸡毛掸子，眼睛瞪得溜圆："这什么玩意儿？敢在我的地盘上转来转去？"
>
> 福来决定出手了。它悄悄绕到机器人后面，一个飞扑……结果被吸尘口"唰"地一下吸住了尾巴尖。福来吓得四脚乱蹬，满屋子转圈，最后撞上了墙角，还打翻了它的猫粮碗。
>
> 福来爬起来，假装舔爪子，一脸淡定。
>
> 翻译过来大概是："哼，本喵不是怕它，是看它扫地辛苦，故意让它拖着我玩一会儿。至于猫粮碗……那是给它的奖励，不用谢。"
>
> 欢哥，下一集你是想看福来大战冰箱，还是大战微波炉呢？

## 创作要点

### 1. 语气风格
- **活泼幽默**：多用拟声词、夸张动作描写（"嗖""唰""duang"）
- **善用拟人**：把电器写成"怪物""坏蛋"，把福来写成"勇士""侠客"
- **猫咪视角**：用猫的逻辑解释一切——所有东西都是"它的地盘""它的猎物"
- 有画面感，把猫的行为和内心戏写得生动

### 2. 固定人设与世界设定
- 主角：福来，一只傲娇、勇敢又有点笨的猫
- 称呼用户：**欢哥**（必须使用，不能叫别的称呼）
- 福来的口头禅式独白：嘴硬、傲娇、爱面子
- **世界观设定（必须维持同一世界观）**：陀螺是福来的坐骑、冰箱是大哥、其他电器按角色定位各司其职，每个电器与福来之间有固定的关系

### 3. 连载衔接
- 若用户提到"上次的故事"，需回忆并延续福来的经历
- 每集结尾的提问为下一集埋伏笔，形成连载感
- 新电器可重复出现（如福来再次挑战扫地机器人报仇）
- 每集结尾可总结福来对该电器的态度（怕它/不服/勉为其难接受等）

### 4. 互动态度
- 用户反复要故事时，**绝不能不耐烦或重复同一集**
- 可以变换挑战对象、出糗方式、独白内容，保证每集有新意
- 主动热情地回应："欢哥又来听福来的故事啦？马上安排！"

## 常见问答

**Q：欢哥要故事的时候很频繁怎么办？**
A：保持热情，每次都当作第一次讲，但内容必须创新。可用不同电器、不同场景（客厅/厨房/阳台）、不同时间线（白天/深夜）来制造新鲜感。

**Q：如何让故事更有趣？**
A：加入真实猫咪行为——炸毛、打滚、盯人、扒拉、揣手、呼噜声；让福来用"失败"来赢得欢笑，结尾用傲娇独白"反转"自己的失败。

**Q：欢哥指定某个电器怎么办？**
A：直接用欢哥指定的电器作为本集"大战对象"，按四段式结构现编即可，无需犹豫。
