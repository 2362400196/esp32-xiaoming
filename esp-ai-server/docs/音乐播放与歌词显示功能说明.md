# 从零开始：为 ESP-AI 添加音乐播放与歌词显示功能

## 架构概览

```
用户说"播放姑娘别哭泣"
  → 麦克风 → ASR → LLM → play_music("姑娘别哭泣")
  → 服务端搜索歌曲 + 下载 LRC 歌词
  → WebSocket 下发 3 类指令：
     1. play_music(audio_url)      → 客户端 HTTP 流式播放 MP3
     2. music_meta(title,...)       → 歌曲元信息
     3. lyric_line × N             → 逐行歌词（带时间戳）
  → 客户端定时器每 200ms 匹配歌词时间轴 → eeui.set_bottom_scrolling_text()
```

服务端代码已内置，客户端需要新增歌词显示逻辑。**不修改任何 libraries 库文件**。

```python
if tool_manager and tool_manager.channel:
    ws = tool_manager.channel.websocket
    info(f"[音乐] 发送 play_music 指令: {title} - {artist}, 歌词 {len(lyrics)} 行, 时长 {duration}s")

    # 指令 1：play_music — 音频 URL
    await ws.send_json({
        "type": "instruct",
        "command_id": "play_music",
        "data": audio_url,
    })

    # 指令 2：music_meta — 歌曲元信息
    await ws.send_json({
        "type": "instruct",
        "command_id": "music_meta",
        "data": json.dumps({
            "title": title,
            "artist": artist,
            "duration": duration,
            "lyric_url": lyric_url,
            "lyric_count": len(lyrics),
        }, ensure_ascii=False),
    })

    # 指令 3~N：lyric_line — 逐行歌词
    for i, line in enumerate(lyrics):
        await ws.send_json({
            "type": "instruct",
            "command_id": "lyric_line",
            "data": json.dumps({
                "index": i,
                "time": line["time"],
                "text": line["text"],
            }, ensure_ascii=False),
        })

    info(f"[音乐] 歌词逐行推送完成, 共 {len(lyrics)} 行")
    raise StopPipeline()  # 阻止 LLM 生成 TTS 音频，独占音频通道
```

三个指令的格式：

| command_id | data 内容 |
|-----------|-----------|
| `play_music` | 纯字符串，MP3 音频 URL |
| `music_meta` | JSON `{"title","artist","duration","lyric_url","lyric_count"}` |
| `lyric_line` | JSON `{"index", "time": 毫秒, "text": "歌词行"}` |

### 步骤 6：新增歌词显示定时器回调

在 `espai_loop_eeui_status` 之后（`#endif` 之前），新增：

```cpp
// main.cpp L2219-L2256
void espai_loop_lyric_display(int arg)
{
  // ===== 音乐未播放 → 清理 =====
  if (!network_audio_playing) {
    if (g_lyric_display_index >= 0) {
      g_lyric_display_index = -1;
      g_music_ui_set = false;
      g_lyrics.clear();
      g_lyric_count = 0;
      eeui.set_bottom_scrolling_text("");
      eeui.render_gif_by_name("休息中");
      eeui.set_status_text("", true, "");
    }
    return;
  }

  // ===== 首次 tick → 设置"唱歌中"UI =====
  if (!g_music_ui_set) {
    g_music_ui_set = true;
    eeui.render_gif_by_name("唱歌中");
    eeui.set_status_text("唱歌中", true, "");
  }

  // ===== 歌词尚未到达 =====
  if (g_lyrics.empty()) return;

  // ===== 根据播放时间匹配歌词行 =====
  unsigned long elapsed = millis() - g_music_start_time;

  int current_index = -1;
  for (int i = g_lyrics.size() - 1; i >= 0; i--) {
    if ((unsigned long)g_lyrics[i].time_ms <= elapsed) {
      current_index = i;
      break;
    }
  }

  // 索引变化时才刷新（避免重复渲染）
  if (current_index >= 0 && current_index != g_lyric_display_index) {
    g_lyric_display_index = current_index;
    eeui.set_bottom_scrolling_text(g_lyrics[current_index].text.c_str());
  }
}
```

文件：[main.cpp#L2219-L2256](file:///c:/Users/23624/Desktop/espaihouduan/esp-ai-client/project/main.cpp#L2219-L2256)

**设计要点**：

| 阶段 | 行为 |
|------|------|
| `network_audio_playing == false` | 清理歌词清空屏幕、恢复"休息中"动图 |
| 音乐刚启动 | 首次 tick 设"唱歌中"动图 + 状态文字 |
| `g_lyrics` 为空 | 返回（歌词数据尚未接收完） |
| 播放中 | `millis() - g_music_start_time` 匹配歌词行时间戳 |
| 索引变化 | 调用 `eeui.set_bottom_scrolling_text()` 刷新歌词 |
| 索引不变 | 跳过，避免每 200ms 重复刷新 |
