## 三、核心数据流

### 3.1 完整语音对话流程

```mermaid
sequenceDiagram
    participant ESP as ESP32 设备
    participant WS as websocket_endpoint(纯IO)
    participant CTRL as SessionController
    participant SESS as Session(含4 Workers)
    participant ASR as ASR 服务
    participant LLM as OpenAI LLM
    participant TTS as 火山引擎 TTS

    ESP->>WS: {"type":"start"}
    WS->>CTRL: dispatch("start")
    CTRL->>SESS: interrupt() / 取消旧会话
    CTRL->>SESS: FSM → TTS (唤醒音频)
    CTRL->>ESP: play_audio(0010) + 唤醒音频帧
    ESP-->>WS: {"type":"client_out_audio_over"}
    SESS->>SESS: FSM → ASR
    SESS->>ASR: 预连 WebSocket
    WS->>ESP: {"status":"iat_start"}

    loop 持续接收音频
        ESP->>WS: 二进制音频帧
        WS->>SESS: queue_audio()
        SESS->>ASR: 转发音频流(限流)
        ASR-->>SESS: 识别中间结果
    end

    ASR-->>SESS: VAD 静音检测 → final 结果
    SESS->>WS: {"status":"iat_end"}
    SESS->>ESP: instruct(文本回显)

    WS->>CTRL: on_vad_end(text)
    CTRL->>SESS: run_pipeline(text)

    par Pipeline 4 Workers 并发
        SESS->>LLM: LLM Task: stream_chat
        LLM-->>SESS: token 流 → text_queue
        SESS->>SESS: Splitter Task: 断句 → audio_queue
        SESS->>TTS: TTS Task: synthesize(限流)
        TTS-->>SESS: 音频帧 → send_queue
        SESS->>ESP: Sender Task: 逐帧发送
    end

    LLM-->>LLM: tool_calls 处理(非流式继续)

    SESS->>SESS: 全部句子合成完毕
    SESS->>ESP: end_frame + tts_real_end
    ESP-->>WS: {"type":"client_out_audio_over"}
    WS->>CTRL: dispatch("client_out_audio_over")
    CTRL->>SESS: 自动启动下一轮 ASR
```

## 十、新增 `app/session/` 模块详解

### 10.1 背压队列策略

| 队列 | 容量 | 满时策略 | 原因 |
|------|------|----------|------|
| `text_queue` | 10 | **丢弃最旧句子** | 旧句子已经过时，保留最新回复 |
| `audio_queue` | 20 | **阻塞等待** | 必须保证语音完整，不能丢句子 |
| `send_queue` | 50 | **丢弃最新帧** | 防止 WS 发送阻塞拖死整个链路 |

### 10.2 并发控制

| 信号量 | 默认值 | 配置项 | 保护对象 |
|--------|--------|--------|----------|
| `asr_semaphore` | 5 | `ASR_MAX_CONCURRENCY` | ASR WebSocket 发送音频 |
| `tts_semaphore` | 10 | `TTS_MAX_CONCURRENCY` | TTS 火山引擎 API 调用 |

### 10.3 中断机制

```
interrupt():
  1. cancel_event.set()      → 通知所有 Worker 停止
  2. stop_asr()              → 停止 ASR 流
  3. queues.clear_all()      → 清空全部 3 个队列
  4. splitter.reset()        → 重置断句器
  5. runtime.reset()         → 重置 Runtime 状态
  6. set_tts_playing(False)  → 更新播放状态
  7. send end_frame          → 通知设备停止播放
```
