## 1. 项目概述

### 1.1 项目简介

ESP-AI Server 是一个面向硬件设备的实时语音交互后端服务，为 ESP32 等智能硬件提供完整的语音交互解决方案。

### 1.2 核心设计理念

- **低延迟流式处理**：全链路流式架构，ASR→LLM→TTS 无缝衔接
- **预连接优化**：ASR 和 TTS 预连接，减少握手延迟
- **可插拔设计**：基类 + 工厂模式，易于扩展新的服务厂商
- **状态机管理**：精确控制会话生命周期
- **硬中断机制**：全链路 cancel_event，支持用户随时打断

### 1.3 技术栈

| 组件 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 开发语言 |
| FastAPI | 0.100+ | Web 框架 |
| Uvicorn | 最新 | ASGI 服务器 |
| websockets | 14.2 | WebSocket 库 |
| OpenAI SDK | 1.0+ | LLM 调用 |
| MCP | 1.27+ | 外部工具协议 |

### 1.4 核心特性

```
设备连接
    │
    ▼

    │
    ▼
创建 Session
    │
    ▼
pre_connect_asr()  ← 预连 ASR
    │
    ▼

    │
    ▼
FSM → ASR
    │
    ▼
流式识别 (asr_streaming_task)
    │
    ▼
VAD 静默 / asr_end
    │
    ▼
FSM → LLM
    │
    ▼
Pipeline 启动 (4 Workers)
    ├─ LLM Worker      → 流式生成
    ├─ Splitter Worker → 分句
    ├─ TTS Worker      → 合成音频
    └─ Sender Worker   → 发送到设备
    │
    ▼
播放完成 (client_out_audio_over)
    │
    ▼
自动启动下一轮 ASR ← 连续对话
```

### 4.3 通道与状态机 (channel.py)

#### SessionFSM 状态机

```python
class SessionState:
    IDLE = "idle"      # 待机
    ASR = "asr"        # 识别中
    LLM = "llm"        # 思考中
    TTS = "tts"        # 播放中

class SessionFSM:
    """会话状态机"""

    VALID_TRANSITIONS = {
        SessionState.IDLE: [SessionState.ASR, SessionState.TTS],
        SessionState.ASR: [SessionState.LLM, SessionState.IDLE],
        SessionState.LLM: [SessionState.TTS],
        SessionState.TTS: [SessionState.ASR, SessionState.IDLE],
    }

    async def set(self, new_state: str):
        """设置新状态（带校验）"""
        async with self.lock:
            if new_state not in self.VALID_TRANSITIONS.get(self.state, []):
                error(f"非法状态转换: {self.state} → {new_state}")
                return
            self.state = new_state

    def get(self) -> str:
        return self.state
```

#### WSChannel 发送通道

```python
class WSChannel:
    """WebSocket 发送通道（单写队列化）"""

    def __init__(self):
        self.websocket = None
        self.send_queue = asyncio.Queue(maxsize=200)
        self._send_task = None
        self._send_gen = 0  # generation counter for interrupt

    def bind(self, websocket):
        """绑定 WebSocket 连接"""
        self.websocket = websocket
        self.connected = True
        self._send_gen += 1
        self._send_task = asyncio.create_task(self._send_loop(self._send_gen))

    async def _send_loop(self, gen: int):
        """发送循环（独立协程）"""
        while self.connected:
            msg = await self.send_queue.get()
            if gen != self._send_gen:  # generation 校验
                break
            await self._send(msg)

    async def send_json(self, data: dict):
        await self.send_queue.put({"kind": "json", "data": data})

    async def send_bytes(self, data: bytes):
        await self.send_queue.put({"kind": "bytes", "data": data})

    async def interrupt_send_loop(self) -> int:
        """打断发送循环（用于 TTS 中断）"""
        self._send_gen += 1  # 旧循环自然退出
        if self._send_task and not self._send_task.done():
            self._send_task.cancel()
        cleared = self.clear_queue()
        if self.connected and self.websocket:
            self._send_task = asyncio.create_task(self._send_loop(self._send_gen))
        return cleared
```

### 4.4 会话管理 (session.py)

#### Session 核心设计

```python
class Session:
    """会话核心类"""

    def __init__(self, device_id: str, ...):
        self.device_id = device_id
        self.session_id = str(uuid.uuid4())

        # 状态机
        self.fsm = fsm

        # 背压队列
        self.queues = BackpressureQueues()

        # 运行时
        self.runtime = SessionRuntime(channel, fsm, audio_processor)

        # 取消事件
        self.cancel_event = asyncio.Event()

        # TTS 状态
        self.tts_playing = False
        self.tts_playback_done = asyncio.Event()
        self.tts_audio_ended = asyncio.Event()

    async def run_pipeline(self, text: str):
        """运行完整 Pipeline"""
        # 1. 更新状态机
        await self.fsm.set(SessionState.LLM)

        # 2. 启动 4 个 Workers
        workers = [
            asyncio.create_task(self._llm_worker(text)),
            asyncio.create_task(self._splitter_worker()),
            asyncio.create_task(self._tts_worker()),
            asyncio.create_task(self._sender_worker()),
        ]

        # 3. 等待完成
        await asyncio.gather(*workers, return_exceptions=True)

    async def interrupt(self):
        """中断会话"""
        # 1. 触发取消事件
        self.cancel_event.set()
        await asyncio.sleep(0.05)
        self.cancel_event.clear()

        # 2. 清空队列
        self.queues.clear_all()

        # 3. 停止 ASR
        self.runtime.stop_asr()

        # 4. 停止发送
        await self.channel.interrupt_send_loop()

        # 5. 发送结束帧
        await self.channel.send_bytes(self.voice_generator.make_end_frame())
```

#### 背压队列设计

```python
class BackpressureQueues:
    """三级背压队列（有损降级）"""

    def __init__(self):
        self.text_queue = asyncio.Queue(maxsize=10)  # 句子队列（丢旧句）
        self.audio_queue = asyncio.Queue(maxsize=20)  # 音频队列（阻塞）
        self.send_queue = asyncio.Queue(maxsize=50)   # 发送队列（丢帧）

    async def put_text(self, seq_id: int, text: str):
        """放入句子（满则丢弃最旧的）"""
        if self.text_queue.full():
            try:
                self.text_queue.get_nowait()
                self.text_queue.task_done()
            except asyncio.QueueEmpty:
                pass
        await self.text_queue.put((seq_id, text))

    def clear_all(self):
        """清空所有队列"""
        for q in [self.text_queue, self.audio_queue, self.send_queue]:
            while not q.empty():
                try:
                    q.get_nowait()
                    q.task_done()
                except asyncio.QueueEmpty:
                    break
```

```python
    @abstractmethod
    async def recognize_streaming(self, audio_chunks: list[bytes]) -> str:
        """流式识别"""
        pass

    async def pre_connect(self):
        """预连接（可选实现）"""
```

```python
        }

        # 签名
        signature = self._generate_signature(params)
        params["signature"] = signature

        query_string = "&".join([f"{k}={v}" for k, v in params.items()])
        return f"wss://asr.cloud.tencent.com/asr/v2/{self.app_id}?{query_string}"

    async def pre_connect(self):
        """预连接 ASR WebSocket"""
        if self._pre_ws:
            await self._pre_ws.close()
        url = self._build_url()
        self._pre_ws = await websockets.connect(url, max_size=20*1024*1024)
        return self._pre_ws

    def take_pre_ws(self):
        """取出预连接 WS"""
        ws = self._pre_ws
        self._pre_ws = None
        return ws
```

```python
from openai import AsyncOpenAI

class OpenAILLM(BaseLLMProcessor):
    """OpenAI 兼容接口实现"""

    def __init__(self, tool_manager=None, user_config=None):
        api_key = user_config.llm_api_key if user_config else LLM_API_KEY
        base_url = user_config.llm_base_url if user_config else LLM_BASE_URL
        self.client = AsyncOpenAI(api_key=api_key, base_url=base_url)
        self.tool_manager = tool_manager

    async def stream_chat(self, messages: list):
        """流式对话 + Function Calling"""
        tools = self.tool_manager.get_openai_tools_schema() if self.tool_manager else None

        # 第一轮：流式生成
        response = await self.client.chat.completions.create(
            model=self.model,
            messages=messages,
            stream=True,
            tools=tools,
        )

        full_text = ""
        raw_tool_calls = {}

        async for chunk in response:
            delta = chunk.choices[0].delta if chunk.choices else None
            if delta:
                if delta.content:
                    full_text += delta.content
                    yield delta.content

                if delta.tool_calls:
                    for tc in delta.tool_calls:
                        idx = tc.index
                        if idx not in raw_tool_calls:
                            raw_tool_calls[idx] = {"id": "", "function_name": "", "arguments": ""}
                        if tc.id:
                            raw_tool_calls[idx]["id"] = tc.id
                        if tc.function:
                            raw_tool_calls[idx]["function_name"] = tc.function.name
                            raw_tool_calls[idx]["arguments"] += tc.function.arguments

        # 如果有工具调用，执行并继续
        if raw_tool_calls:
            messages.append({
                "role": "assistant",
                "content": full_text,
                "tool_calls": [...],
            })

            for tc_data in raw_tool_calls.values():
                func_args = json.loads(tc_data["arguments"]) if tc_data["arguments"] else {}
                tool_result = await self.tool_manager.call_tool(
                    tc_data["function_name"],
                    func_args
                )
                messages.append({
                    "role": "tool",
                    "tool_call_id": tc_data["id"],
                    "content": str(tool_result),
                })

            # 非流式继续
            final_response = await self.client.chat.completions.create(
                model=self.model,
                messages=messages,
                stream=False,
            )
            yield final_response.choices[0].message.content
```

```python
class TTSSession:
    """复用的 TTS 会话（一个 WS 连接合成多个句子）"""

    def __init__(self, tts, websocket, session_id: str):
        self._tts = tts
        self._websocket = websocket
        self._session_id = session_id
        self._seq = 0
        self._closed = False

    async def synthesize(self, text: str, cancel_event=None):
        """合成单句"""
        self._seq += 1
        req = {
            "user": {"uid": str(uuid.uuid4())},
            "req_params": {
                "speaker": self._tts.voice_type,
                "audio_params": {
                    "format": "mp3",
                    "sample_rate": 24000,
                    "speed_ratio": self._tts.speed_ratio,
                },
                "text": text,
            },
        }

        await full_client_request(self._websocket, json.dumps(req).encode())

        while True:
            if cancel_event and cancel_event.is_set():
                return
            msg = await receive_message(self._websocket)
            if msg.type == MsgType.AudioOnlyServer and msg.payload:
                yield msg.payload
            elif msg.type == MsgType.FullServerResponse:
                if msg.event == EventType.SessionFinished:
                    return
                elif msg.event == EventType.SessionFailed:
                    error("TTS 会话失败")
                    return

class VolcEngineTTS(BaseTTSProcessor):
    """火山引擎 TTS 实现"""

    async def create_session(self, cancel_event=None) -> TTSSession:
        """创建可复用会话"""
        last_error = None
        for attempt in range(3):
            try:
                websocket = await self._create_connection()
                self._active_websockets.append(websocket)
                session_id = str(uuid.uuid4())
                return TTSSession(self, websocket, session_id)
            except Exception as e:
                last_error = e
                await asyncio.sleep(1.0)
        raise last_error
```

```python
import inspect

_registry = {}

class StopPipeline(Exception):
    """停止 Pipeline 异常（用于独占工具）"""
    pass

def tool(name=None, description=None):
    """工具装饰器"""
    def decorator(func):
        tool_name = name or func.__name__
        tool_desc = description or (func.__doc__ or "").strip()

        # 自动从签名生成参数 Schema
        sig = inspect.signature(func)
        properties = {}
        required = []

        for param_name, param in sig.parameters.items():
            if param_name in ["self", "cls", "tool_manager", "channel"]:
                continue

            prop = {"type": "string"}
            ann = param.annotation
            if ann is int:
                prop["type"] = "integer"
            elif ann is bool:
                prop["type"] = "boolean"

            if param.default is inspect.Parameter.empty:
                required.append(param_name)
            else:
                prop["default"] = param.default

            properties[param_name] = prop

        parameters_schema = {
            "type": "object",
            "properties": properties,
        }
        if required:
            parameters_schema["required"] = required

        _registry[tool_name] = ToolDefinition(
            name=tool_name,
            description=tool_desc,
            func=func,
            parameters=parameters_schema,
        )
        return func
    return decorator

def auto_discover():
```

```python
class PerUserToolManager:
    """Per-user 工具管理器"""

    def __init__(self, shared, channel=None):
        self._shared = shared
        self.channel = channel
        self._mcp_clients = []
        self._mcp_tool_map = {}

    async def initialize_mcp(self, mcp_servers: dict):
        """初始化 MCP 客户端"""
        for name, config in mcp_servers.items():
            client = MCPClient(config["url"], name, ...)
            success = await client.connect()
            if success:
                self._mcp_clients.append(client)
                for schema in client.get_tools_schema():
                    func_name = schema["function"]["name"]
                    self._mcp_tool_map[func_name] = client

    def get_all_tools_schema(self):
        """获取所有工具 Schema"""
        schemas = get_openai_tools_schema()
        for client in self._mcp_clients:
            schemas.extend(client.get_tools_schema())
        return schemas

    async def call_tool(self, tool_name: str, arguments: dict) -> str:
        """调用工具"""
        builtin = get_tool(tool_name)
        if builtin:
            sig = inspect.signature(builtin.func)
            kwargs = dict(arguments)
            if "tool_manager" in sig.parameters:
                kwargs["tool_manager"] = self
            if "channel" in sig.parameters and self.channel:
                kwargs["channel"] = self.channel
            result = builtin.func(**kwargs)
            if asyncio.iscoroutine(result):
                result = await result
            return str(result)

        if tool_name in self._mcp_tool_map:
            return await self._mcp_tool_map[tool_name].call_tool(tool_name, arguments)

        return f"未找到工具: {tool_name}"
```

### 5.6 插件前端 SDK 通信协议

插件前端（iframe 内）通过 postMessage 与父应用通信，所有 API 调用都走父应用代理，无需自己管理 JWT token。

#### 消息协议

**插件前端 → 父应用（请求）：**

```javascript
window.parent.postMessage({
  type: 'api',           // 固定值
  id: 1,                 // 递增 ID，用于匹配响应
  path: '/api/v1/plugins/weather/tool/test_weather_query',  // API 路径（不含 base URL）
  method: 'POST',        // 请求方法
  body: {                // 请求体（GET 请求为 null）
    args: { city: "北京" },
    device_id: "D8:3B:DA:6D:D9:3C"
  }
}, '*')
```

**父应用 → 插件前端（响应）：**

```javascript
window.addEventListener('message', function(e) {
  const msg = e.data
  if (msg.type === 'apiResult' && msg.id === 1) {
    // msg.data  - 响应数据
    // msg.status - HTTP 状态码
    // msg.error - 错误信息（如果有）
  }
})
```

#### 前端 SDK 封装

```javascript
// 在插件 frontend/index.html 中使用
let _apiId = 0
const _pending = {}

window.addEventListener('message', function(e) {
  const msg = typeof e.data === 'object' ? e.data : {}
  if (msg.type === 'apiResult' && _pending[msg.id]) {
    _pending[msg.id](msg)
    delete _pending[msg.id]
  }
})

async function sdkApi(path, opts = {}) {
  return new Promise((resolve, reject) => {
    const id = ++_apiId
    _pending[id] = (msg) => {
      if (msg.error) reject(new Error(msg.error))
      else resolve({ data: msg.data, status: msg.status })
    }
    window.parent.postMessage({
      type: 'api', id, path,
      method: opts.method || 'GET',
      body: opts.body || null
    }, '*')
  })
}

// 使用示例：调用天气插件工具
// 插件内部使用 http_get_json（SDK）调用高德 API，Key 不暴露到浏览器
const data = await sdkApi('/api/v1/plugins/weather/tool/test_weather_query', {
  method: 'POST',
  body: { args: { city: '北京' }, device_id: 'D8:3B:DA:6D:D9:3C' }
})
```

#### 通用插件工具调用接口

所有插件前端调用插件工具统一走以下接口，不需要为每个插件单独建路由：

```
POST /api/v1/plugins/{plugin_name}/tool/{tool_name}
```

**请求体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `args` | object | 工具参数（如 `{"city": "北京"}`） |
| `device_id` | string | 设备 ID（可选，用于注入设备插件配置） |

**原理：** 后端通过 `get_tool(tool_name)` 获取工具定义，注入 `tool_manager` 上下文（含设备插件配置），然后直接调用插件工具函数。插件工具内部使用 `http_get_json` 等 SDK 函数获取数据，**API Key 等敏感信息不暴露到浏览器**。

#### 现有消息类型

| 方向 | type | 用途 |
|------|------|------|
| 插件 → 父应用 | `ready` | 通知页面已加载 |
| 插件 → 父应用 | `toast` | 显示提示消息 |
| 插件 → 父应用 | `api` | 通过父应用代理调用后端 API |
| 父应用 → 插件 | `apiResult` | API 调用结果返回 |
| 父应用 → 插件 | `deviceChanged` | 推送当前设备信息 |

```python
session.cancel_event.set()
await asyncio.sleep(0.1)
session.cancel_event.clear()
```

#### 3. 清空队列

```python
session.queues.clear_all()
```

### 8.3 常见问题

#### Q1: TTS 首字延迟高？

A: 检查是否启用了预连接，查看日志确认 `pre_connect` 是否成功。

#### Q2: ASR 识别不准确？

A: 检查采样率配置是否与设备匹配（16000 vs 8000）。

#### Q3: 如何排查连接断开？

A: 查看日志中的 `trace_id`，使用 `grep trace_id=xxx logs/app.log` 追踪。

#### Q4: 如何优雅关闭服务？

A: 发送 SIGTERM 信号，服务会等待活跃连接完成（最多 `SHUTDOWN_GRACE_PERIOD` 秒）。
