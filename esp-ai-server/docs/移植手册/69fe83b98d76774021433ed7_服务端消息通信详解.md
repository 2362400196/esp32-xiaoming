# ESP-AI Server 服务端向客户端消息通信详解

## 📋 概述

本文档详细说明 ESP-AI Server 在设备连接后，向客户端（ESP32等硬件设备）发送的所有消息类型、触发场景、消息格式和使用说明。

**版本**: v2.82.70

## 🔌 消息通信概览

```
┌─────────────────┐                         ┌─────────────────┐
│   ESP32 设备     │                         │  ESP-AI Server   │
│  (客户端)        │◄────────────────────────│  (服务端)        │
│                 │     WebSocket 连接        │                  │
│                 │                         │                  │
│                 │► ──── 音频数据 ──── ►    │                  │
│                 │     JSON 消息           │                  │
│                 │     控制指令            │                  │
└─────────────────┘                         └─────────────────┘
```

## 📊 消息类型总览

服务端向客户端发送的消息主要分为以下几类：

| 类别 | 消息类型 | 格式 | 说明 |
|------|----------|------|------|
| **连接相关** | `play_audio_ws_conntceed` | JSON | 连接成功通知 |
| **心跳保活** | `keepalive` | JSON | 心跳包 |
| **会话状态** | `session_status` | JSON | 会话状态变化 |
| **音频数据** | 二进制帧 | bytes | TTS 音频流 |
| **控制指令** | `instruct` | JSON | 控制命令 |
| **播放控制** | `play_audio` | JSON | 播放任务标识 |
| **文本指令** | `instruct` | JSON | LLM 回复文本 |
| **唤醒音频** | `play_audio` | JSON+bytes | 唤醒提示音 |
| **时间同步** | `stc_time` | JSON | 时间戳同步 |
| **图片显示** | `show_image` | JSON | 显示图片 |
| **情绪表情** | `emotion` | JSON | 情绪表情 |
| **清除图片** | `clear_image` | JSON | 清除屏幕 |
| **会话控制** | `session_start/stop` | JSON | 会话开始/结束 |
| **Pong 响应** | `pong` | JSON | 心跳响应 |

## 1️⃣ 连接建立阶段

### 1.1 连接成功通知

**触发时机**: 设备成功建立 WebSocket 连接后

**发送代码**:
```python

```

**消息格式**:
```json

}
```

**用途**: 通知设备 WebSocket 连接已建立，等待设备响应

**设备响应**: 设备应发送 `play_audio_ws_conntceed` 确认

---

### 1.2 连接确认音频

**触发时机**: 收到设备的 `play_audio_ws_conntceed` 响应后

**文件位置**: `app/websocket/handler.py` 第 382-396 行

**发送代码**:
```python
async def _play_connect_audio(channel: WSChannel):
    vg = _shared_session_controller.voice_generator
    await channel.send_json({"type": "stc_time", "stc_time": "1234567890"})
    await asyncio.sleep(0.3)
    await channel.send_json({"type": "play_audio", "tts_task_id": SID_CONNECTED})
    await asyncio.sleep(0.1)
    await channel.send_json({"type": "session_status", "status": "tts_chunk_start"})
    await asyncio.sleep(0.1)
    await channel.send_bytes(vg.make_end_frame(SID_CONNECTED))
    await asyncio.sleep(0.1)
    await channel.send_json({"type": "session_status", "status": "tts_chunk_end"})
    await asyncio.sleep(0.5)
    await channel.send_json({"type": "session_status", "status": "session_end"})
    await asyncio.sleep(0.1)
    await channel.send_text("session_end")
```

**发送顺序**:
1. `{"type": "stc_time", "stc_time": "1234567890"}` - 时间戳同步
2. `{"type": "play_audio", "tts_task_id": "0001"}` - 播放任务标识
3. `{"type": "session_status", "status": "tts_chunk_start"}` - 开始状态
4. 二进制帧 - 结束帧（表示无音频数据）
5. `{"type": "session_status", "status": "tts_chunk_end"}` - 结束状态
6. `{"type": "session_status", "status": "session_end"}` - 会话结束
7. `"session_end"` - 文本会话结束

**SID 常量定义** (`app/config.py`):
```python
SID_CONNECTED = "0001"  # 连接成功
SID_TTS = "0010"        # TTS 音频
SID_WAKE = "1001"       # 唤醒音频
SID_REST = "1002"       # 待机
```

## 2️⃣ 心跳保活阶段

### 2.1 Keepalive 心跳

**触发时机**: 设备空闲时定期发送

**文件位置**: `app/websocket/handler.py` 第 228-238 行

**发送代码**:
```python
async def idle_keepalive():
    count = 0
    while not session._closed:
        interval = 1 if fsm.get() == SessionState.TTS else 3
        await asyncio.sleep(interval)
        if session._closed:
            break
        channel.send_json_nowait({"type": "keepalive", "ts": int(time.time())})
        count += 1
        if count % 10 == 0:
            info(f"[Keepalive] {device_key[:8]}: {count}次")
```

**消息格式**:
```json

  "ts": 1234567890
}
```

**发送频率**:
- TTS 播放期间: 每 1 秒
- 其他时间: 每 3 秒

**用途**: 保持连接活跃，检测连接状态

## 5️⃣ 音频数据传输

### 5.1 TTS 音频帧

**触发时机**: Pipeline 运行期间，TTS 合成完成后

**文件位置**: `app/session/session.py` 第 491 行, `app/session/session.py` 第 570 行

**发送代码**:
```python
# 生成帧
frame = self.voice_generator.make_tts_frame(SID_TTS, audio_chunk, "00")
# 发送帧
await self.channel.send_bytes(frame)
```

**帧格式** (`app/tts/voice_generator.py`):
```python
class VoiceGenerator:
    def make_tts_frame(self, session_id, audio_data, status="00"):
        """
        帧结构：
        - 会话ID (4字节 utf-8)
        - 会话状态 (2字节 utf-8)
        - 原始音频数据
        """
        sid = session_id.encode("utf-8")
        ss = status.encode("utf-8")
        return sid + ss + audio_data
```

**帧结构详解**:
```
┌────────────────┬───────────┬─────────────────┐
│   session_id   │   status  │   audio_data    │
│   (4 bytes)    │ (2 bytes) │   (variable)    │
├────────────────┼───────────┼─────────────────┤
│     "0010"     │   "00"    │   PCM音频数据    │
└────────────────┴───────────┴─────────────────┘
```

**status 状态码**:
| 状态码 | 含义 |
|--------|------|
| `"00"` | 正常音频帧 |
| `"01"` | (保留) |
| `"02"` | (保留) |
| `"03"` | 结束帧 |

### 5.3 唤醒提示音

**触发时机**: 设备唤醒时（配置启用）

**文件位置**: `app/device/wake_audio.py` 第 66-93 行

**发送代码**:
```python
async def play(self, channel, user_config=None):
    audio_data = await self.ensure_cache(user_config=user_config)
    
    # 发送播放指令
    await channel.send_json({"type": "play_audio", "tts_task_id": SID_TTS})
    await channel.send_json({"type": "session_status", "status": "tts_chunk_start"})
    
    # 分块发送音频
    _TOTAL = len(audio_data)
    sent = 0
    while sent < _TOTAL:
        chunk = audio_data[sent : sent + _CHUNK_SIZE]
        sent += len(chunk)
        frame = self._voice_generator.make_tts_frame(SID_TTS, chunk, "00")
        await channel.send_bytes(frame)
        await asyncio.sleep(0.02)
    
    # 发送结束帧
    await channel.send_bytes(self._voice_generator.make_end_frame(SID_TTS))
    await channel.send_json({"type": "session_status", "status": "tts_real_end"})
```

**音频来源优先级**:
1. 本地 MP3 文件: `app/audio/dou.mp3`
2. TTS 合成: 使用配置的 TTS 引擎合成 `WAKE_TEXT`

**分块大小**: `_CHUNK_SIZE = 2048` 字节

**用途**: 播放"我在呢"等唤醒提示音

## 📝 注意事项

### 1. 消息顺序

某些消息必须按特定顺序发送，例如:
- `play_audio` 必须在音频帧之前
- `session_start` 必须在 `session_status: iat_start` 之前

### 2. 时间间隔

发送关键消息后建议添加短暂延迟:
```python
await asyncio.sleep(0.1)  # 100ms
```

### 3. 错误处理

所有发送操作都应包含错误处理:
```python
try:
    await channel.send_json(data)
except Exception as e:
    warning(f"发送失败: {e}")
```

### 4. 心跳保活

确保连接不被防火墙断开:
- TTS 播放期间: 每 1 秒
- 其他时间: 每 3 秒

## 🎯 最佳实践

### 1. 使用 WSChannel

始终通过 `WSChannel` 发送消息，不要直接操作 WebSocket:
```python
# ✅ 正确
await channel.send_json({"type": "keepalive", "ts": ts})

# ❌ 错误
await websocket.send_json({"type": "keepalive", "ts": ts})
```

### 2. 非阻塞发送

对于心跳等非关键消息，使用 `send_json_nowait`:
```python
channel.send_json_nowait({"type": "keepalive", "ts": ts})
```

### 3. 状态同步

确保状态机状态与发送的消息一致:
```python
await fsm.set(SessionState.TTS)
await channel.send_json({"type": "session_status", "status": "tts_chunk_start"})
```

### 4. 资源清理

断开连接时确保所有资源已释放:
```python
await channel.close()
await session.close()
```

```python
# 完整的 TTS 播放流程
async def play_tts(channel, text):
    vg = VoiceGenerator()
    tts = create_tts_processor()
    session = await tts.create_session()
    
    # 1. 发送播放指令
    await channel.send_json({"type": "play_audio", "tts_task_id": "0010"})
    await asyncio.sleep(0.1)
    
    # 2. 发送开始状态
    await channel.send_json({"type": "session_status", "status": "tts_chunk_start"})
    await asyncio.sleep(0.1)
    
    # 3. 流式发送音频
    async for chunk in session.synthesize(text):
        if chunk:
            frame = vg.make_tts_frame("0010", chunk, "00")
            await channel.send_bytes(frame)
            await asyncio.sleep(0.02)
    
    # 4. 发送结束帧
    await channel.send_bytes(vg.make_end_frame("0010"))
    await asyncio.sleep(0.1)
    
    # 5. 发送结束状态
    await channel.send_json({"type": "session_status", "status": "tts_real_end"})
    
    await session.close()
```
