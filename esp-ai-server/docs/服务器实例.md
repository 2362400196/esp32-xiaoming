# 服务器实例使用指南

本文档介绍如何在 ESP-AI 服务器中使用设备控制模块。

## 设备连接

设备通过 WebSocket 连接时，使用查询参数 `device_id` 标识设备。

```
ws://server:port/?key=xxx
```

### get_all_devices()

获取所有当前连接的设备 ID 列表。

```python
from app.device import get_all_devices

device_ids = get_all_devices()
```

### get_device(device_id)

获取指定设备的详细信息。

```python
device = get_device("my_device")
# 返回 {"channel", "ctx", "fsm", "user_config"}
```

## 说话功能

### speak(device_id, text)

让指定设备说话。

```python
from app.device import speak

await speak("my_device", "你好，这是一段测试语音")
```

### speak_all(text)

让所有设备说话。

```python
from app.device import speak_all

await speak_all("大家好，欢迎使用")
```

### speak_direct(channel, ctx, fsm, text)

在自定义工具中使用，直接播放 TTS。

```python
from app.tools import tool
from app.device import speak_direct
from app.tools import StopPipeline

@tool()
async def my_tool(channel=None, ctx=None, fsm=None):
    if channel:
        await speak_direct(channel, ctx, fsm, "这是工具调用的语音")
        raise StopPipeline()
```

## 唤醒功能

### wakeup(device_id)

唤醒设备（从待机状态唤醒）。

```python
from app.device import wakeup

await wakeup("my_device")
```

### wakeup_all()

唤醒所有设备。

```python
from app.device import wakeup_all

await wakeup_all()
```

## 后续扩展

### 添加新的设备控制功能

在 `app/device/` 目录下创建新文件：

```python
# app/device/volume.py
async def set_volume(device_id, level):
    device = get_device(device_id)
    if not device:
        return False
    channel = device["channel"]
    await channel.send_json({
        "type": "instruct",
        "command_id": "set_volume",
        "data": str(level)
    })
    return True
```

在 `app/device/__init__.py` 中导出：

```python
from app.device.volume import set_volume

__all__ = [
    "speak",
    "speak_all",
    "speak_direct",
    "wakeup",
    "wakeup_all",
    "set_volume"
]
```

## 完整示例

```python
import asyncio
from app.device import speak, speak_all, wakeup, get_all_devices

async def main():
    devices = get_all_devices()
    if devices:
        await wakeup(devices[0])
        await speak(devices[0], "你好，欢迎使用")
        await speak_all("系统测试完成")

asyncio.run(main())
```

## API 参考

### 函数列表

| 函数 | 说明 |
|------|------|
| `speak(device_id, text)` | 让指定设备说话 |
| `speak_all(text)` | 让所有设备说话 |
| `speak_direct(channel, ctx, fsm, text)` | 直接播放 TTS（工具调用） |
| `wakeup(device_id)` | 唤醒设备 |
| `wakeup_all()` | 唤醒所有设备 |
| `get_device(device_id)` | 获取设备信息 |
| `get_all_devices()` | 获取所有设备 ID |
| `get_all_devices_with_32bit()` | 获取所有设备（包含 32 位 ID） |

### 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `device_id` | `str` | 设备标识符 |
| `text` | `str` | 要合成的文本 |
| `channel` | `WSChannel` | WebSocket 通道 |
| `ctx` | `SessionContext` | 会话上下文 |
| `fsm` | `SessionFSM` | 会话状态机 |
| `user_config` | `UserConfig` | 用户配置（可选） |
| `need_wakeup` | `bool` | 是否发送唤醒序列（可选） |
