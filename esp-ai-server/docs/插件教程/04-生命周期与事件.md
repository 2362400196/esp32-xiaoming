# 04 - 生命周期与事件

## 1. 生命周期钩子：on_startup / on_shutdown

插件可以在 `plugin.py` 中定义**模块级**的生命周期钩子函数，框架在加载/卸载时自动调用（实现见 `src/infrastructure/plugin_loader.py` 的 `_call_plugin_hook`）：

```python
# plugin.py

@tool(name="my_init_demo", description="演示工具")
async def my_init_demo() -> str:
    return "hi"


async def on_startup():
    """插件加载成功、工具注册完成之后调用。支持同步或 async 函数。"""
    # 适合：初始化连接、预热缓存、加载本地数据
    ...


async def on_shutdown():
    """插件卸载时调用（服务停止或热重载前）。"""
    # 适合：释放资源、落盘状态
    ...
```

### 触发时机

| 钩子 | 触发点 | 备注 |
|------|--------|------|
| `on_startup` | 插件加载成功（工具已注册、服务已声明）之后 | 热重载时每次加载都会触发 |
| `on_shutdown` | 插件卸载时（服务停止 / 热重载前） | 先停止沙箱进程/注销工具，再调钩子，最后清理模块 |

### 行为约定

- 钩子可以是同步函数或 `async def`（返回 awaitable 时框架会 await）。
- **钩子抛出的异常只记 warning 日志，不影响插件加载/卸载结果**。
- **内置插件**（`src/plugins/`，进程内加载）：钩子正常执行。
- **安装插件**（`data/plugins/installed/`，子进程沙箱）：插件代码运行在子进程，主进程没有对应模块对象，`on_startup` / `on_shutdown` **目前会被静默跳过**（框架已预留调用点）。沙箱插件的初始化/清理请改用：
  - 初始化：工具首次调用时惰性初始化（模块级单例）；
  - 清理：依赖 SDK 的自动资源管理（如 WebSocket 连接池 idle 超时回收）。

## 2. 事件订阅：`src/use_cases/sdk/events.py`

框架内置一个**进程内发布/订阅事件系统**（`src/use_cases/sdk/events.py`）：

```python
from src.use_cases.sdk.events import (
    subscribe, unsubscribe, publish,
    EVENT_DEVICE_ONLINE,     # 设备上线（payload: device_id）
    EVENT_DEVICE_OFFLINE,    # 设备离线（payload: device_id）
    EVENT_SESSION_START,     # 语音会话开始（payload: device_key）
    EVENT_SESSION_END,       # 设备会话结束/断连（payload: device_key）
    EVENT_WECHAT_MESSAGE,    # 微信消息（payload: chat_id, text）
)


def _on_device_online(device_id: str = "", **_):
    plugin_log(f"设备上线: {device_id}")


sub_id = subscribe(EVENT_DEVICE_ONLINE, _on_device_online, plugin_name="my_plugin")
# 不再需要时：
unsubscribe(sub_id)
```

### API 说明

| 函数 | 签名 | 说明 |
|------|------|------|
| `subscribe` | `(event: str, callback: Callable, plugin_name: str = "") -> str` | 订阅事件，返回订阅 ID。payload 以**关键字参数**传入回调（建议回调加 `**_` 兜底，兼容 payload 扩展） |
| `unsubscribe` | `(sub_id: str) -> bool` | 取消订阅；订阅不存在返回 `False` |
| `publish` | `(event: str, **payload) -> None` | 发布事件（一般由框架调用）；无人订阅时为空操作 |

### 行为约定

- 纯进程内、无持久化；服务重启后订阅失效，插件应在 `on_startup` 中重新订阅。
- 回调异常只记日志，**不影响发布方主流程和其他订阅者**。
- 协程回调自动包装为后台任务执行，不阻塞发布方。

### 可用性限制（重要）

- 该事件系统是**进程内**实现，目前**未接入沙箱 RPC 通道**，也未通过 `_plugin_helpers` 统一导出：
  - **内置插件**：直接 `from src.use_cases.sdk.events import subscribe` 使用。
  - **沙箱插件**：`src.use_cases.sdk.events` 不在沙箱放行名单内，**不能 import**（会被沙箱拒绝）。沙箱插件的事件订阅能力为规划中项（需协议层新增 `event_subscribe` / 事件推送消息），当前请用轮询（`device_is_online` 等）替代。
